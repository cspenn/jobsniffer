# Contributing

`jobsniffer` is a personal, AI-assisted fork of [speedyapply/JobSpy](https://github.com/speedyapply/JobSpy).

**This project does not send pull requests upstream, and will not accept pull requests intended for
forwarding upstream.** That is a deliberate choice, not an oversight: the upstream maintainers have
not asked for AI-edited contributions, and mixing AI-authored diffs into their history without
invitation is not something this fork wants to do — a sensitive topic in open source right now, and
one worth respecting rather than testing.

If you want to contribute to the original project, please go to
[speedyapply/JobSpy](https://github.com/speedyapply/JobSpy) and work there directly.

Issues and pull requests against *this* fork are welcome for changes that only make sense here
(scraper repairs for indeed/linkedin/zip_recruiter, the SQLite-oriented extractor, tests). They will
never be forwarded upstream on your behalf.
